# Modern Anki

These values are managed by the add-on; you normally don't need to edit them.

- `browser_columns_version` — tracks whether the Browse (Advanced) table columns have been set to the add-on's default (Sort Field, Tags, Deck). Set to `0` to re-apply the default columns on next start.
- `browser_layout_version` — tracks whether the Browse pane proportions (sidebar / table / editor) have been applied once. Set to `0` to re-apply them.

Everything else (theme toggle, Med School presets, Edit page) has no configuration here; use the controls in the app.
